# Tulpa

Tulpa is a menu-bar app for the Mac that works while you sleep. Each night it reads your recent Claude Code and Codex sessions and notes, picks a few things you would be glad to find done, does them with the subscription you already have, and leaves the results in an inbox for the morning.

**[Download the latest release](https://github.com/steerbits/tulpa/releases/latest)** (Apple silicon, macOS 14 or later).

Open the DMG, double-click Tulpa, and let it move itself to Applications. It lives in the menu bar; the first-run window shows what it found and what it would do tonight. Installed copies update themselves.

Needs Claude Code or Codex installed and signed in. Everything is read on your Mac; only the coding agent you already use sees excerpts.
